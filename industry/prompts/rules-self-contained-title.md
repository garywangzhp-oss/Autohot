【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：品牌名 / 车型名 / 平台名 / 车型代号 / 公司名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是车型代号 / 配置代码 / 没信息量的 teaser（如 "Day 1"、"The next chapter"、"重磅发布"、"Coming soon"）时，结合【来源】和正文把主体补进标题。例：原标题 "Day 1" + 来源 "BMW Group PressClub" → "宝马发布新一代车型"；原标题 "X5 xDrive40i" + 来源和正文是宝马 → "宝马 X5 xDrive40i 上市"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体品牌或车型时，用上位词（如"一款纯电 SUV""某新势力车企"）兜底，绝不凭"行业常识"编一个具体品牌、车型或型号。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / First Drive / Comparison 这类解释、分析、教程或评测标题，中文标题必须保留这个类型；不能因为正文谈到一款已经存在的车型、配置或新数据，就改写成"发布 / 推出 / 上市 / 开启交付"。只有原标题明确宣布了发布、推出、上市或交付，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的品牌、车型或平台名。
   例：原标题 "How the new 800V platform cuts charging time" + 来源和正文明确是某品牌 → "某品牌 800V 平台如何缩短充电时间"，不能写成 "某品牌发布 800V 平台"。
   例：原标题 "First drive: the new electric SUV" + 来源和正文明确是某品牌某车型 → "某品牌某车型首次试驾体验"，不能只写成缺主体的 "一款纯电 SUV 首次试驾"。
